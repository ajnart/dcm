# The repository becomes ajnart/self-host and ships only the Go CLI and its one small skill

The legacy skill tree (about 790 files, 6 MB, 78,000 words of TypeScript workflows) loaded into agents for a path the Go CLI now covers in a few files, and maintaining both doubled every change. We move the `new-cli` directory to the root and delete the legacy tree in one pull request (#192), then rename `ajnart/self-host` to `ajnart/self-host` (#193), rather than splitting that directory into a fresh repository: the rename keeps issues, pull requests, releases and stars, GitHub redirects the old URLs, and `install.sh` and `release.Repo` already follow redirects. The one skill lives at `skills/self-host/SKILL.md`; everything else an agent needs comes from `self-host skill` and the CLI's own JSON. Old `.selfhost/` projects from the TypeScript CLI are not migrated.
