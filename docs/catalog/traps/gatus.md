# Gatus traps

## Pitfalls

- The starter configuration checks only Gatus itself; readiness is not evidence of monitoring other services.
- Default in-memory history does not survive restart; the recipe selects SQLite on a project-owned volume.
- No administrator account or API key is generated by this recipe.

## Security

- Keep the unauthenticated dashboard and status API on loopback or a separately approved private route.
- Review target URLs and alert credentials before adding real monitors; neither is in the starter recipe.
