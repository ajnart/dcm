# Speedtest Tracker traps

## Pitfalls

- Frequent tests consume bandwidth and can distort application traffic or provider usage limits.
- The pinned shared setup checks the seeded administrator inside the exact Laravel container and creates one scoped Sanctum token. If token creation commits but its one-time plaintext is lost before private storage, stop for explicit recovery rather than creating another token. Browser login UX and an actual measurement remain separate acceptance checks.

## Security

- Keep the web UI private, replace the documented default admin login on first start, and treat public IP, ISP, and location metadata as private operational data.
