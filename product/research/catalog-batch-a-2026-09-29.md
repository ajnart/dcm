# Catalog batch A: headless first-run feasibility

Checked 2026-09-29. Audiobookshelf now has a source-backed private Compose candidate and deterministic first-root HTTP adapter. It is not live-tested or a complete media library: exact media paths and restart-persistence acceptance remain separate. Do not infer acceptance from an image starting or an HTTP response.

| App | Source-backed finding | Missing decision or primitive |
| --- | --- | --- |
| actual-budget | Official Docker image persists `/data` and serves on 5006. Actual's documented API is a Node client, not a REST endpoint; its server login is password-only. [Docker](https://actualbudget.org/docs/install/docker/), [API](https://actualbudget.org/docs/api/), [server configuration](https://actualbudget.org/docs/config/) | Existing `manual-first-admin` requires a username and cannot honestly model Actual. Need password-only onboarding and a version-pinned, verified way to set and check the password without exposing it in command arguments or logs. |
| adguard-home | First launch is an installation wizard and DNS interface choice affects host networking. [Docker](https://adguard-dns.io/kb/adguard-home/docker/), [secure setup](https://adguard-dns.io/kb/adguard-home/running-securely/) | Need explicit DNS bind/port inputs and verified setup API contract before any DNS traffic is diverted. |
| archive-team-warrior | Official image documents `DOWNLOADER` and `SELECTED_PROJECT` environment bootstrap; after `projects/config.json` exists, environment changes are ignored. [Official Dockerfile README](https://github.com/ArchiveTeam/warrior-dockerfile) | Need selected public downloader name/project and a fixed image tag. On 2026-09-29, the official registry's `latest` manifest had digest `sha256:19337aa9157e04f6cdb8f7c6f8c98e27d14efb0d9525334995fbdb036b95e1ca`, but the source version tag `20260722.01` returned 404 and its tag-list endpoint did not enumerate tags; the recipe contract requires a non-`latest` tag. External archiving activity must be approved explicitly. |
| aria2 | The catalog currently has no verified upstream image; exposing its RPC endpoint without a secret would be unsafe. [Upstream repository](https://github.com/aria2/aria2) | Verify an image and a private RPC-secret file contract before a recipe. |
| audiobookshelf | The official image supports fixed release tags, persists `/config` and `/metadata`, and serves container port 80. Pinned v2.37.0 source exposes `GET /status`, one-time `POST /init` with `newRoot`, and `POST /login`, whose response includes a root-user type. [Docker install](https://github.com/audiobookshelf/audiobookshelf-docs/blob/master/docs/documentation/install/2.docker-compose-install.md), [release](https://github.com/advplyr/audiobookshelf/releases/tag/v2.37.0), [server routes](https://github.com/advplyr/audiobookshelf/blob/v2.37.0/server/Server.js), [login route](https://github.com/advplyr/audiobookshelf/blob/v2.37.0/server/Auth.js) | Implemented `recipe.json` and `setup.ts`: private port, generated root password, pre-send one-time checkpoint, separate login verification. No media directory is guessed; library selection and restart proof remain outstanding. |
| authelia | Official standalone Compose example requires configuration, multiple secret files, PostgreSQL and a deliberate domain/proxy design. [Docker deployment](https://www.authelia.com/integration/deployment/docker/) | Cannot pick domains, authentication backend, access rules, or proxy integration on the user's behalf. Needs generated configuration templates and explicit inputs. |
| authentik | Identity provider requires database and security-sensitive bootstrap decisions. [Docker Compose installation](https://docs.goauthentik.io/install-config/install/docker-compose/) | Verify pinned multi-service deployment, admin bootstrap and ingress inputs as one bounded unit. |
| bazarr | Official LinuxServer image requires UI setup parameters before config can be saved. [Image guide](https://docs.linuxserver.io/images/docker-bazarr/) | Sonarr/Radarr locations and subtitle providers require selected inputs; do not invent defaults. |
| beszel | Hub/agent topology and host access are separate trust decisions. [Hub installation](https://www.beszel.dev/guide/hub-installation), [agent installation](https://beszel.dev/guide/agent-installation) | Requires explicit agent pairing and host-access plan, not just a hub recipe. |
| bookstack | Existing catalog identifies a community image and has no verified deterministic first admin. [LinuxServer image guide](https://docs.linuxserver.io/images/docker-bookstack/) | Verify database, app key and credential bootstrap without shipping a default password. |
| borgmatic | Backup targets, encryption, retention and an isolated restore are user-specific. [Official configuration docs](https://torsion.org/borgmatic/docs/how-to/set-up-backups/) | A generic empty container would not be a useful or safe backup. Needs exact source/destination and restore plan. |

Only the Audiobookshelf candidate and adapter are implemented; no app in this batch is claimed deployed or accepted.
