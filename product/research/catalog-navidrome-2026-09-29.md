# Navidrome v0.64.0 first-admin contract — 2026-09-29

The existing recipe pins `deluan/navidrome:0.64.0`; upstream [v0.64.0 release](https://github.com/navidrome/navidrome/releases/tag/v0.64.0) identifies the matching source. Its [Docker guide](https://www.navidrome.org/docs/installation/docker/) supports persistent `/data`, read-only `/music`, port 4533, and a selected runtime user.

In pinned source, the [UI auth provider](https://github.com/navidrome/navidrome/blob/v0.64.0/ui/src/authProvider.js) submits JSON `{username,password}` to `POST /auth/createAdmin` on first use and `/auth/login` thereafter. The [server router](https://github.com/navidrome/navidrome/blob/v0.64.0/server/server.go) mounts those routes under `/auth`. The [auth handlers](https://github.com/navidrome/navidrome/blob/v0.64.0/server/auth.go) return 403 from `createAdmin` when any user exists, create an admin otherwise, and answer both successful requests with a payload containing user identity, `isAdmin`, and a session token. Login returns 401 for invalid credentials. The [CLI user guide](https://navidrome.org/docs/usage/admin/cli/user/) explicitly requires an existing admin, so it cannot bootstrap this instance.

The adapter checks the exact running saved project and generated alphanumeric password, tries a fresh login first, then sends at most one approved first-admin request with a persisted pre-send checkpoint. A successful login without a matching setup checkpoint is not adopted, even if the credentials happen to match. It validates the returned admin identity and confirms a fresh password login. After an ambiguous create outcome it only attempts login; it never blindly replays creation. The transient session token and Subsonic credentials in the response are neither saved nor exposed. No API key is created. These native UI routes are pinned implementation details, not a guaranteed stable external API.

This source check does not prove live image behavior, music scan/playback, or restart persistence. Those remain separate direct acceptance checks. No Docker or full test suite was run.
