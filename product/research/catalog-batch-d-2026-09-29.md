# Catalog batch D: first-run evidence and limits

Three bounded v2 Compose candidates are added. Navidrome and Lidarr deliberately retain `manual-first-admin`; Loki has no account bootstrap and uses a read-only readiness adapter. None claims ingestion or full application acceptance from Compose start.

| App | Primary evidence | Decision |
| --- | --- | --- |
| Navidrome | [Official Docker guide](https://www.navidrome.org/docs/installation/docker/) documents port 4533, `/data`, read-only `/music`, and numeric Compose `user`; [official CLI user guide](https://navidrome.org/docs/usage/admin/cli/user/) says an admin must already exist and the first admin is created in the web UI; [official Docker tags](https://hub.docker.com/r/deluan/navidrome/tags) list the pinned 0.64.0 image. | Private recipe; first-admin headless setup blocked by the documented CLI bootstrap restriction. An unversioned UI HTTP call was not substituted. |
| Lidarr | [LinuxServer image documentation](https://docs.linuxserver.io/images/docker-lidarr/) documents PUID/PGID/TZ, `/config`, and port 8686; its [package versions](https://github.com/linuxserver/docker-lidarr/pkgs/container/lidarr/versions) list `version-3.1.0.4875`. | Private recipe with an owner-selected shared `/data` path. First-admin/authentication and music root remain explicit acceptance gates until the exact pinned API flow is proven. |
| Loki | [Grafana Docker guide](https://grafana.com/docs/loki/latest/setup/install/docker/) pins `grafana/loki:3.7.0`, documents port 3100 and `GET /ready`, and notes the default UID/GID 10001; the [v3.7.0 Dockerfile](https://github.com/grafana/loki/blob/v3.7.0/cmd/loki/Dockerfile) bundles its default config, and the [bundled config](https://github.com/grafana/loki/blob/v3.7.0/cmd/loki/loki-docker-config.yaml) writes under `/loki`. [Grafana authentication guidance](https://grafana.com/docs/loki/latest/operations/authentication/) says Loki has no built-in authentication. | Private single-node recipe with persistent `/loki` volume and no account. Setup verifies only documented readiness; collector wiring, ingestion, retention, and restart persistence remain separate. No in-container shell healthcheck is used because recent official images removed shell utilities. |

Remaining assigned apps—Keycloak, Kopia, Linkwarden, LLDAP, Mayan EDMS, MinIO, and NetBird—were not changed. Their first-run contracts and dependencies need separate source-backed design; no guessed Compose configuration or API writes were added.

Validation: focused catalog validation was attempted. It currently stops at an unrelated concurrently added Grafana recipe/catalog image mismatch, before it can report on these recipes. No Docker, live apply, broad tests, or secret handling was performed.
