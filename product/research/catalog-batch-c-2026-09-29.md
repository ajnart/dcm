# Catalog batch C — 2026-09-29

## Implemented

- **Grafana**: pinned OSS image `grafana/grafana:13.2.2`, private port 3000, persistent volume, generated administrator password passed through Grafana's documented `GF_SECURITY_ADMIN_PASSWORD__FILE` setting. Setup authenticates with Basic auth against `GET /api/user` and checks server-admin identity. No data source, dashboard, alert or restart acceptance is implied. Sources: [official Docker installation](https://grafana.com/docs/grafana/latest/setup-grafana/installation/docker/), [Docker configuration and secret-file setting](https://grafana.com/docs/grafana/latest/setup-grafana/configure-docker/), [User HTTP API](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/api-legacy/user/), [13.2.2 upstream release](https://github.com/grafana/grafana/releases/tag/v13.2.2).

## Deferred

The other assigned apps did not receive a recipe or adapter. Their safe deployment cannot be represented as an unattended default with the available catalog inputs: Frigate requires camera streams, credentials, retention and hardware selection; Gluetun requires provider/protocol credentials and a fail-closed egress test; HAProxy and Headscale require explicit DNS/TLS/ingress ownership; Home Assistant and Homebridge need LAN discovery/device and plugin choices. FreshRSS and Glances are candidates for a later bounded pass after version-pinned official image and first-run contracts are checked. Gatus requires an operator-supplied `/config/config.yaml` per its [official Compose example](https://github.com/TwiN/gatus/tree/master/.examples/docker-compose); the current shared planner accepts host-path selection only for its media-data bind, so its Gatus recipe was removed rather than advertising an unplannable deployment. Its [official image](https://github.com/TwiN/gatus/pkgs/container/gatus) and [documented `/health` probe](https://github.com/TwiN/gatus/blob/master/.examples/kubernetes/gatus.yaml) remain verified catalog facts, not an install path. No host deployment or live first-run was attempted.
