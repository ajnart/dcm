# self-host

Install and operate self-hosted apps with Docker Compose from one binary.

```bash
npx self-host
npm i -g self-host
```

Runs on Linux and macOS (amd64/arm64). On Windows, use WSL2.
This package ships the prebuilt release binary through a platform package; nothing is downloaded at install time.

Docs: https://self-host.fyi · Source: https://github.com/ajnart/self-host
