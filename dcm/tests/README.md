# Docker Compose Validation Tests

This directory contains tests to validate the Docker Compose files generated by this application.

## Tests Overview

The tests perform the following validations:

1. **Individual Service Validation** (`validate-compose.test.ts`, needs Docker): Tests each service individually to ensure the Docker Compose configuration for each service is valid.
2. **Combined Services Validation** (`validate-compose.test.ts`, needs Docker): Tests all services together to ensure they work properly when combined in a single Docker Compose file.
3. **Container Schema Validation** (`validate-all-containers.test.ts`): Tests that all container definitions meet the required schema and use proper environment variables.
4. **Networks** (`validate-networks.test.ts`): Tests that compose files with `networks` and `volumes` sections pass the validator and that wrong indentation is rejected.
5. **Templates** (`templates.test.ts`, `template-selection.test.ts`): Test that Template definitions are well formed, have unique ids and reference existing containers, and that selecting or unselecting a Template adds or removes only its containers.
6. **Export**: `export.test.ts` tests `buildExport` (`src/lib/export`): selection, install-only Apps, service dedupe, port conflicts, `.env` generation (generated secrets from an injected `secretFor`), notes and the self-host command.

## Running the Tests

Run the tests with [Bun](https://bun.sh/). Only the Docker Compose validation needs Docker; every other test runs without it.

```bash
# Run every test except the Docker Compose validation
bun run test

# Run only Docker Compose validation (needs Docker)
bun run test:compose

# Run only container schema validation
bun run test:containers

# Run only the Template tests
bun run test:templates
```

## Test Requirements

- [Bun](https://bun.sh/) for running the tests
- For `test:compose` only: Docker running, with Docker Compose V2 (comes with Docker Desktop or can be installed separately)

## Test Results

The test suite will output:

- Results for each individual service test
- Results for combined services test
- Schema validation results for all containers

## What's Being Tested

The Docker Compose validation tests:

1. Generate a Docker Compose file with `buildExport` for the service(s)
2. Create an environment file with default settings
3. Run `docker compose config` to validate the syntax and structure

The container schema validation tests:

1. Validate each container definition against the required schema
2. Check that proper environment variables are being used
3. Verify that hardcoded values aren't used for common environment variables

This ensures that all Docker Compose files generated by the application are valid and follow best practices.
