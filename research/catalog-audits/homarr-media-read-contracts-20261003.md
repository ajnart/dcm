requires `integrationId`; many-integration middleware requires `integrationIds`

Every verification call supplies exactly the selected integration. Empty arrays
are legitimate idle data, not an error. Error/failure envelopes must not pass.
Aggregate item identities are bound to the selected integration, not merely
checked as strings. Seerr statistics require exactly one provider and counter
object for the single selected integration; empty user/request/release arrays
remain legitimate. Independent review found and closed these false-pass cases
in the generic decoder and focused fixture; this is still synthetic evidence.
